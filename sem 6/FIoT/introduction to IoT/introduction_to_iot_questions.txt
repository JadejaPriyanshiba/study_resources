Topic: 1.1 IoT Definition

Section: Multiple Choice Questions
1. What is the most accurate definition of the Internet of Things (IoT)?
(a) A network of laptops and servers connected via the internet.
(b) A system of interconnected computing devices, mechanical and digital machines, that have the ability to transfer data over a network without requiring human-to-human interaction.
(c) A software protocol used for sending emails.
(d) A global system of interconnected computer networks that uses the Internet protocol suite (TCP/IP).
2. In the context of IoT, the term "Things" primarily refers to:
(a) Abstract software concepts and algorithms.
(b) Only household appliances like refrigerators and washing machines.
(c) Physical objects embedded with sensors, software, and other technologies to connect and exchange data.
(d) The internet backbone and network infrastructure.
3. The fundamental goal of an IoT system is to:
(a) Replace all human jobs with automated systems.
(b) Create a more complex version of the internet.
(c) Collect data from the physical world, share it over a network, and use it to create value or action.
(d) Increase the sales of smartphones and mobile devices.
4. Which statement best distinguishes IoT from traditional Machine-to-Machine (M2M) communication?
(a) M2M uses a point-to-point communication channel, while IoT uses a network of networks (the internet) for wider connectivity.
(b) M2M communication is always faster than IoT communication.
(c) IoT devices cannot communicate with each other, unlike M2M devices.
(d) M2M is a newer technology that has replaced IoT.
5. The characteristic of IoT that allows devices of different manufacturers and different technologies to work together is known as:
(a) Scalability
(b) Heterogeneity
(c) Security
(d) Dynamic Nature
6. A smart thermostat adjusting the room temperature based on the weather forecast and the user's presence is an example of which key IoT characteristic?
(a) Enormous scale
(b) Unique identity
(c) Dynamic and self-adapting nature
(d) Connectivity
7. Which of the following is NOT a common application domain of IoT?
(a) Smart Home Automation
(b) Industrial Control Systems (ICS)
(c) Connected Healthcare
(d) Standalone offline word processing
8. In a smart agriculture application, sensors monitoring soil moisture and triggering an irrigation system is an example of:
(a) Data privacy management
(b) An IoT-enabled feedback and control loop
(c) A non-functional system requirement
(d) A standalone embedded system
9. What is the primary function of an IoT Gateway?
(a) To generate data using its own sensors.
(b) To directly display data to the end-user.
(c) To act as a bridge between IoT devices (sensors/actuators) and the cloud.
(d) To perform complex, long-term data analytics.
10. In the key components of an IoT system, the Cloud is primarily responsible for:
(a) Powering the physical sensors and devices.
(b) Providing a user interface for mobile phones.
(c) Manufacturing the physical hardware.
(d) Scalable data storage, processing, and management.
11. The 'Analytics' component in an IoT system is used to:
(a) Convert analog sensor signals to digital signals.
(b) Encrypt data during transmission.
(c) Extract meaningful insights and patterns from the collected data.
(d) Provide network connectivity to the devices.
12. In a smart parking system, which of the following represents the 'Thing'?
(a) The mobile application used by the driver.
(b) The ultrasonic sensor detecting a car in a parking spot.
(c) The cloud server that stores parking availability data.
(d) The data visualization dashboard.
13. In the standard four-layer IoT architecture, which layer is responsible for collecting data from the physical environment?
(a) Application Layer
(b) Data Processing Layer
(c) Network Interface Layer
(d) Sensing Layer
14. The transmission of data from an IoT gateway to the cloud using technologies like Wi-Fi, 4G, or Ethernet happens at which layer?
(a) Sensing Layer
(b) Network Interface Layer
(c) Data Processing Layer
(d) Application Layer
15. The task of converting raw sensor data into a meaningful format, often referred to as data pre-processing, typically occurs in the:
(a) Application Layer
(b) User Interface Layer
(c) Data Processing Layer
(d) Physical Thing Layer
16. The Application Layer in the IoT architecture is primarily responsible for:
(a) Acquiring data from physical objects.
(b) Transmitting data packets over a network.
(c) Delivering application-specific services and data visualization to the user.
(d) Filtering analog noise from sensor readings.
17. A major design challenge for small, battery-operated IoT sensors, especially in remote locations, is:
(a) High-speed internet connectivity
(b) Large screen for user display
(c) Low power consumption
(d) Heavy computational capability
18. Unauthorized access to a connected pacemaker or a smart car's control system represents which critical IoT challenge?
(a) Connectivity challenge
(b) Power requirement challenge
(c) Security and Personal Safety challenge
(d) Data extraction challenge
19. The ability of an IoT system to handle and process data from billions of interconnected devices relates to the challenge of:
(a) Connectivity
(b) Power Management
(c) Complexity and Scalability
(d) User Interface Design
20. Ensuring that a smart camera can correctly identify a human face in varying light conditions is an example of overcoming which IoT challenge?
(a) Data extraction from a complex environment
(b) Network connectivity
(c) Device power requirements
(d) Data privacy regulations
